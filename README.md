3. Hướng dẫn cách chạy

Yêu cầu máy đã cài sẵn Node.js và npm
-Chạy Phần A (Class Component)
cd part-a-class
npm install
npm run dev

-Chạy Phần B (Function Component + Hooks)
cd part-b-hooks
npm install
npm run dev

-Chạy song song cả 2 phần:
Ở cột danh sách file bên trái của VS Code, nhấn chuột phải vào tên thư mục part-a-class (hoặc part-b-hooks).

Chọn dòng Open in Integrated Terminal.

Một tab Terminal mới xuất hiện ở phía dưới và đường dẫn đã trỏ sẵn vào đúng thư mục bạn vừa bấm.Thực hiện chạy "npm run dev"
